Royal Watches | El tiempo con estilo
*Guía Oficial del Proyecto*

Versión: 1.0

Estado: En desarrollo

1. Descripción del Proyecto

Royal Watches es una aplicación web premium enfocada en la venta de relojes elegantes inspirados en marcas reconocidas.

El objetivo del proyecto no es únicamente desarrollar una tienda online, sino utilizarlo como un entorno de aprendizaje completo para adquirir competencias propias de un desarrollador Full Stack.

Todo el desarrollo estará orientado a comprender profundamente cada tecnología utilizada, evitando el aprendizaje basado únicamente en copiar código.

2. Filosofía del Proyecto

Este proyecto seguirá una filosofía de aprendizaje progresivo.

Antes de utilizar cualquier tecnología, librería o framework se estudiará:

por qué fue creado;
qué problema resolvía;
cómo funciona internamente;
cuándo conviene utilizarlo;
cuándo no conviene utilizarlo;
buenas prácticas profesionales.

El objetivo es aprender a pensar como un ingeniero de software y no depender de herramientas sin comprender su funcionamiento.

3. Objetivos Generales

Al finalizar el proyecto el estudiante deberá ser capaz de:

construir aplicaciones web desde cero;
diseñar interfaces modernas;
comprender HTML semántico;
dominar CSS moderno;
programar con JavaScript;
comprender React y utilizarlo cuando realmente aporte valor;
desarrollar un backend con Node.js;
trabajar con APIs;
implementar autenticación;
administrar roles y permisos;
utilizar Git profesionalmente;
desplegar aplicaciones en Internet.

Existirán tres tipos principales de usuarios.

Visitante

Puede:

navegar;
consultar productos;
buscar relojes;
contactar la empresa.
Cliente

Puede:

comprar;
administrar su cuenta;
administrar favoritos;

administrar carrito.
Administrador

Puede:

ingresar al panel administrativo;
administrar el sistema según sus permisos.

10. Sistema de Roles y Permisos (RBAC)

El panel administrativo utilizará un sistema de Role-Based Access Control (RBAC).

No todos los administradores tendrán necesariamente los mismos permisos.

Los permisos podrán incluir, entre otros:

Crear productos.
Editar productos.
Eliminar productos.
Crear categorías.
Editar categorías.
Eliminar categorías.
Administrar clientes.
Administrar pedidos.
Administrar estadísticas.
Administrar administradores.
Configurar el sitio.
Gestionar formularios de contacto.

Los permisos serán asignados desde el propio panel administrativo.

11. Super Administrador

Existirá un rol especial denominado Super Administrador.

Inicialmente habrá dos usuarios con este rol.

El Super Administrador podrá:

crear nuevos administradores;
eliminar administradores;
activar o desactivar cuentas;
asignar permisos;
modificar permisos;
cambiar roles;
restablecer contraseñas;
acceder a todas las funciones del sistema.

12. Contacto

La aplicación contará con un formulario funcional.

El formulario permitirá:

registrar solicitudes;
validar datos;
enviar mensajes;
mostrar respuestas claras al usuario.

20. Compromiso

Este proyecto no tiene como objetivo únicamente aprobar un curso o entregar una práctica.

Su propósito es construir una base sólida para el desarrollo web profesional, comprendiendo las tecnologías desde sus fundamentos y adquiriendo la capacidad de diseñar, desarrollar y mantener aplicaciones modernas de forma autónoma.
