# ⌚ Royal Watches

Bienvenido a **Royal Watches**, un proyecto de desarrollo web enfocado en la creación de una tienda online de relojes de lujo.

Este proyecto no solo busca desarrollar una página web funcional y atractiva, sino también documentar mi proceso de aprendizaje en **HTML, CSS y JavaScript**, aplicando buenas prácticas, código semántico y una estructura profesional.

---

## 📖 Descripción

Royal Watches es una tienda online ficticia especializada en replicas de alta calidad de relojes de marcas reconocidas como:

- Rolex
- Hublot
- Richard Mille
- Patek Philippe
- Cartier
- Curren

El objetivo es ofrecer una experiencia de usuario moderna, elegante y responsiva, inspirada en el diseño de las principales marcas del sector.

---

## 🎯 Objetivos del proyecto

- Aprender desarrollo web desde cero.
- Comprender el funcionamiento de HTML, CSS y JavaScript.
- Aplicar HTML semántico y buenas prácticas.
- Desarrollar una interfaz moderna y profesional.
- Implementar animaciones e interactividad.
- Construir un proyecto real para mi portafolio.
